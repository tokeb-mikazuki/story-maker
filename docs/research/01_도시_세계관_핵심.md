# 01. 도시(The City) — 세계관 핵심

> 출처: 나무위키 「도시(Project Moon 세계관)」, 「도시(Project Moon 세계관)/연표」 및 하위 문서 (2026-10 기준, namu.moe 미러로 열람)
> 용도: 시뮬레이터 텍스트/이벤트 작성 시 설정 레퍼런스. **원작 고유명사는 그대로 표기.**

## 1. 한 줄 요약
26개 구로 나뉜 초거대 기업도시. 물리법칙을 무시하는 기술 **특이점**을 쥔 대기업 **날개**가 각 구의 핵심부 **둥지**를 다스리고, 그 바깥 **뒷골목**은 사실상 방치된 무법지대. 정점에는 도시의 금기(연방법)를 정하는 **머리(A·B·C사)**. 사람은 연료·부품 취급이며, "돈이면 거의 다 해결된다."

## 2. 기본 제원
| 항목 | 내용 |
|---|---|

| 인구 | 약 67억 (985년 6월 모종의 사건으로 64억으로 급감). 인구밀도 약 18만/km² |
| 행정구역 | 26구. 1구 중심 나선형(소라껍데기) 배치. 지도엔 25구까지만 표기 (Z사 둥지 미표기, 미스터리) |
| 정치 | 명목상 연방제 / 실질 과두정·기업국가·권위주의 집단지도 |
| 화폐 | **안(眼)**. 지폐·신용카드 형태. 원화와 비슷하거나 약간 높은 물가. 지역화폐(금화, 은자, T사의 '시간')도 존재 |

| 역사 | 최소 200년 이상(해결사 제도는 약 520년 전에도 존재). 특이점 발현 후 새 문명 시작 |

## 3. 공간 구조
### 3.1 둥지 (Nest)
- 각 구의 날개 직할지. 주민 = **깃털**. 살인적인 세금을 내는 대신 "길 가다 죽을 걱정 없는" 삶.
- 이주에는 돈 + **날개의 허가** 필요. 1급 해결사도 정치적 이유로 거부당할 수 있음. 둥지 간 이동은 '입국심사'처럼 검문.
- 안정적으로 살려면 상위 30% 수입(대략 4급 해결사 수준). **월 400만 안 이상 = 둥지 중상위층.**
- 실상: 날개의 사축. K사 '복지 좋은' 직원 최소 근무시간 주 70시간. 입사 계약서에 "필요 시 깃털을 희생" 조항을 몰래 숨김. 퇴사 시 기억 처리 + 퇴직금(이라지만 '말소' 소문).
- "새가 지키는 건 깃털이 아니라 **알(=특이점)**". 깃털 몇 개 빠지는 건 신경 안 씀.
- 날개가 몰락하면 둥지는 뒷골목보다 위험해짐 → 손가락·조직이 점거·약탈(**알박기**). 주민 선택지: ①다른 날개로 이직 ②거액에 해결사 고용 ③점거 조직에 보호비 상납 ④뒷골목으로 도주.
- 둥지와 뒷골목은 일부러 **서로 보이게** 만들어 둠 (둥지 주민엔 우월감+추락 공포, 뒷골목엔 희망 고문). 깃털이 퇴근 후 창밖 '뒷골목의 밤'을 TV처럼 구경하는 묘사 있음.

### 3.2 뒷골목 (Backstreets)
- 둥지를 제외한 구의 나머지 전부. 거미줄처럼 얽힘. 엄밀히 날개 관할이나 방치 → 사실상 무정부.
- 구성: **입시촌**(둥지 입사시험 준비생 마을), 조직, 해결사 사무소, 공방, 식당·반찬가게·대형마트, 학교(등하굣길 위험 → 기숙사제·온라인 학교 多).
- 빈부격차 존재: 평범한 2층 주택가 ~ 닭장 같은 30층 아파트 ~ 판자촌. 보호비를 내는 구역 / 못 내서 매일 목숨 거는 구역.
- 치안 주체: 조직, 해결사 사무소, 츠바이 협회(유료), **자경단**(주민 자발, 츠바이보다 덜 인색).
- **거주구역**: 뒷골목에서 그나마 안전한 곳 (뒷골목의 밤에 한정해 도시의 금기로 보호).
- 구별 특징(확인된 것):
  - 4구(D사): 평범한 빈민가. 연두낭자 출신지.
  - 9구(I사): '음악의 골목'. 안전했으나 최초의 뒤틀림 **피아니스트**로 30만 명 사망, 방치된 폐허.
  - 22구(V사): 사건사고 많음. 천의 바늘 사건, 약지 갤러리.
  - 23구(W사): 식인 요리 문화(피에르의 고기파이, 8인의 셰프).
  - 25구(Y사): 최북단, 추움. 빈민가, 유흥시설 없음. 로쟈·소냐 출신. 대폿집 '동환이네'(파전).

### 3.3 지역 문화권 (4방위)
| 방위 | 복식·문화 |
|---|---|
| 북부 | 고층 건물, 화려한 복장(상의 4겹), 테크웨어, 사이버펑크풍 |
| 남부 | 정장·코트, 차분함. 가장 21세기와 비슷 (원작 주무대) |
| 동부 | 직물 의상, 동아시아풍. 조직 대소사를 대장끼리 **1:1 결전**으로 결정. 일부 십이시 사용. H사·S사 |
| 서부 | 영지 존재, 활·가죽·금속갑옷의 중세풍. 해결사를 '기사'라 부름 |

### 3.4 도시 바깥
- **외곽**: 괴생명체와 추방된 비인간 지성체의 땅(폐기물 처리장). 인간 마을도 있음(구름마을 등). **사냥꾼** = 외곽판 자경단. 외곽 물건은 도시에서 귀한 보물. 외곽→도시 진입도 시험·절차 필요. 외곽 열차 운행.
- **외곽 너머**: 사실상 지옥이자 코즈믹 호러. 아름답고 고요한 별하늘. **별**이 소원을 비틀어 들어줌(1인 1소원). 날개 창립자들이 여기서 특이점의 원천을 얻어왔다는 추측(K사 스테파네트, T사 허버트).
- **대호수**: 도시 남부~외곽. 인어·고래·크랲게. 포경선과 고래잡이 해결사, U사 항구선.
- **유적 / 유적의 심연**: 도시 지하 깊은 곳. 괴물(HE급 이상)과 **유물**(궁니르, 레바테인, 맘브리노의 투구, 오딘의 눈, 천살성도 등). 심연엔 미래미래강·레테(망각의 강).
- **세계의 제일 밑바닥에 존재하는 강(세밑강/우물)**: 인류의 과거·현재·미래의 모든 가능성이 담긴 태고의 바다. 인간의 자아와 직결.

## 4. 법과 금기
| 층위 | 제정 | 위반 시 |
|---|---|---|
| **도시의 금기** (연방법) | 머리 | **발톱** 파견, 대상이 강하면 **조율자**. 불순물 지정 → 제거/외곽 축출. 도망 불가(응시자가 찾아냄). 모든 세력이 반드시 준수 |
| **날개의 금기** (공통) | 날개들 | 급수별. 경미하면 하청 사무소·약식 처벌·물품 몰수, 중하면 직속 금기 사냥꾼 |
| **둥지의 금기** (주법) | 각 날개 | **금기 사냥꾼**(날개 직속 해결사, 대개 2급 이상). 강자면 협상으로 넘어가기도 |

- 금기를 모두 모으면 법전 여러 권. 둥지마다 미덕/금기가 정반대일 수 있음 ("이 둥지는 음식을 남기지 않는 게 미덕, 옆 둥지는 음식 찌꺼기를 빈민에게 던지는 게 미덕").
- 확인된 도시의 금기 예시: 뒷골목의 밤 녹취·조사 금지, 뒷골목의 밤 거주구역 침입·파괴 금지, **사자소생(부활)** 금지, 인간 아닌 지성체(아인종·고도 AI) 금지(관련자까지 처형), 인간과 똑같은 전신의체 금지, 총기 제작 가이드 위반(철갑탄·소음기 금지 등), 세금 미납(3회 경고 후), 특허 대가 미지불.
- **살인 금지는 '도시의 금기'가 아님** — 뒷골목의 낮에 살인하면 규칙 위반이지만, 낮에 납치해서 밤 직전에 밖에 던져두면 청소부가 처리 (층간소음 해결법으로 묘사됨).
- 총기: 탄환에 터무니없는 세금 + 까다로운 제작 면허 → 근접무기 위주 사회. 총은 날개·손가락 같은 부자들 위주(엄지, R사, 마침표 사무소).

## 5. 뒷골목의 밤 & 청소부 (★시뮬레이터 핵심 시간 이벤트)
- 매일 **오전 3:13 ~ 4:34 (80분)**. 뒷골목 한정, 머리가 정한 "모든 것이 허용되는 시간". 예외 규칙은 단 2개: **녹취 금지**, **거주구역 불가침**.
- 둥지 밖에 있는 사람이면 날개 임원·협회 지부장도 예외 없음. 협회 고위 간부를 길 한복판에서 죽여도 허용.
- 안전 확보 최저선: **3급 이상 해결사 고용** (그래도 역부족일 수 있음).
- 역설: 밤이 있기 때문에 낮의 최소한의 예의와 치안이 지켜짐.
- **청소부(Sweepers)**: 머리 산하. 특이점으로 만든 **액체인간**(척추·뇌를 보호복형 의체에 넣고 인간 원료 액체연료 주입). 갈고리로 사람·쓰레기를 녹여 연료로 흡수.
  - 행동 패턴: **20분 청소 → 10분 휴식 × 3파**. 동료 시체 흡수로 회복. 1급 해결사도 2파 버티면 너덜너덜.
  - 쓰는 대상: 길거리 시체, 늦게 돌아다니는 사람, 쓰레기, **미허가 건축물**, **등록 기한 만료 거주구역**.
  - 둥지엔 절대 안 들어감(머리 지시 시 예외). 낮엔 "민폐라서" 자제. 거주구역·주거용 차량 공격 안 함.
  - 매우 예의 바르고 가족적. 서로 '이웃/가족', 우두머리 '어머니'. 사람을 가족으로 바꾸기도 함(외곽 아이들의 천적).
  - 조직에 상납금을 못 내 거주구역에 피신 못 한 '쥐' 가족이 몰살당한 사례.

## 6. 사회 계층·인물군
| 계층 | 설명 |
|---|---|
| 머리 | 조율자(A)·응시자(B)·발톱/처형자(C). 일반인은 평생 볼 일 없음 |
| 날개 임원·이사회 | 둥지의 지배층 |
| 깃털 | 둥지 주민·날개 직원. 블랙기업 월급쟁이 |
| 해결사 | 9급~1급, 특색. 면허제. 둥지에 사는 고등급부터 밑바닥 저등급까지 |
| 조직원 | 손가락~동네 잡범 |
| 공방 장인 | 해결사 면허 + 트레스 협회 공방 시험 |
| 뒷골목 소시민 | 식당·가게·입시생 |
| **쥐** | 최하층. 직업·연줄·돈 없음. 강도·장기매매로 하루살이. 불가촉천민 취급은 아님. 밤엔 조직에 상납해 거주구역 피신 |
| 외곽민 | 도시를 동경 |

## 7. 일상생활 디테일 (텍스트 묘사용)
- **업무**: 종이 서류·수기 위주, 80~90년대풍 컴퓨터. 이메일·인터넷 방송·온라인게임도 있음.
- **통신**: 다이얼 전화, 공중전화, 2G 폴더폰. 스마트폰은 둥지 주민 위주, 984년 기준 최근 보급. GPS 미흡. 생각만으로 원거리 대화하는 장치도.
- **교통**: 자동차(서민까지 보급, 단 구 경계 검문·꼬인 도로·둥지 교통체증), **W사 워프 열차**(빠르고 안전, 비쌈. 1등석), 지하철, 주거용 차량. **비행기 개념 없음**(드론은 있음).
- **교육**: 한국식 입시. 둥지 대학 입학(수능 고득점) = 날개 입사 최소 조건. 학교에서 전투기술 교육. 손가락 운영 학원(약지 예술학원)도.
- **음식**: 현대와 비슷(파전, 우육면, 닭꼬치, 스테이크, 순댓국, 소주). 체인: **햄햄팡팡**(저렴한 샌드위치, 뒷골목마다 있음, 13구 본점, 치킨·만두도), **보살 치킨**(K사, 다리 6개·날개 8개 닭). 기묘한 음식: 민트초코 정어리 아이스크림, 후추고추상추카레맛 파이, **댄싱큥큥**(흔들면 젤리 되는 음료, 원료는 벌레형 괴물 체액, 980년대엔 희귀). 23구 식인 식당.
- **신체**: 뇌 빼고 전부 소모품. 돈만 있으면 팔다리 증발해도 복구. 부자는 사실상 노화·병사 없음. 반대로 일반인은 50세면 노인 취급.
- **장례**: 보편적이지 않음(땅값·휴가 없음). 뒷골목은 도굴 우려로 청소부에게 맡김.
- **죽음의 정의**: 회사마다 다름(부활 기술 때문). 단 사자소생은 금기.
- **패션**: 맨살 노출 적음. 해결사는 격식 있는 정장 선호, 저등급은 눈에 안 띄게. 화려할수록 강자. 강자는 코트를 망토처럼 어깨에 걸침. 문신 = 대개 강화 문신(조직의 상징, 탈퇴 방지).
- **차별**: 인종·성·나이 차별 묘사 없음. 대신 빈부·신분·날개 사상(의체 혐오 등) 기반.
- **언론**: 신문·잡지·선전물. 해결사 3대 잡지 「월간 해결사들」(신입 랭킹), 해결사 사무소 카탈로그.
- **기념일**: 크리스마스 등 + 날개별 기념일.
- **동물**: 평범한 가축·애완동물(고양이 찾기 의뢰), 특이점 개량종, 크랲게, 큥큥이 등.
- **스포츠/오락**: 야구·다이빙·비치발리볼, 노래방, 카지노(J사), 목숨 건 게임 소문. 서커스는 사장.
- **도덕**: 도덕 기준 자체는 현실과 비슷 — 다들 잘못된 걸 **알지만** 살기 바빠 외면. 선역도 범죄자·먼저 덤빈 자는 죽이는 걸 망설이지 않음.

## 8. 강화시술·장비 (스펙 레퍼런스)
- 저렴한 시술만으로 전봇대 뽑는 근력. 고등급은 17층 점프. 성별 신체차 사실상 없음. **시술만으론 강자가 안 됨 — 기량이 핵심.** 유지보수 필수, 막 구르면 약해짐.
- **강화 문신**: 몰락 날개 특이점→퍼블릭 도메인. 물감 품질에 따라 천차만별, 싸구려는 시술 부위가 녹음. 상처 나면 소실.
- **의체**: 고장 나도 교체 가능 → 과격한 전투. 신경 없어 손상 둔감 → 금방 죽음. 자주 쓰는 부위일수록 비쌈.
- **전신의체**: 뇌 빼고 기계. 사람과 똑같은 외형 금지. 욕구는 남아 약/칩 필요. 싸구려는 말 어눌, 뇌수 보충. 고급은 둥지 집 한 채 값. 몸 팔아 목돈 마련 수단. 일방통행.
  - N사는 의체를 '고통 회피'로 경멸, 이단심문관은 학살. 뒤틀림 이후 의체 기피 경향.
- 기타: 약물 강화, 전투 보조 안구(눈이 붉게 빛남), 신체 변형(구 G사·흑수), 강화외골격, 쿨다운(패닉 시 정신력 리셋), 육체 증폭(정신력 낮을 때 신체 증폭).
- **특수 원단**: 재단사가 만드는 옷감. 검을 막아냄. 고급은 멤버십·인맥 필요. 인간 실 추출 기술(사육제).
- 생활 기술: 차원 가방(생물 보관 불가), 기억 소거(감정은 못 지움)/기억 파쇄(싸구려, 부작용), 기억 이식, 인지 필터, 인지 저해, 공간 왜곡, HP약(하룻밤에 화상·골절 치료, 5급도 부담없이 씀), 간이 보존 붕대, 날씨 조정(비싸서 거의 안 씀), 제논의 거북나선(고문), 개념소각기.

## 11. 연표 요약 (시뮬레이터 시점 선택용)
- 900년대 이전: 특이점 탄생 → 26 날개 → 머리 출범 → 해결사·하나 협회 → 순차적으로 12협회. 기계 숙청의 날(의체 사용자 학살). 혈귀 전쟁(온건파 승). 라만차랜드(780년대).
- 900년 이후: 칼리·롤랑 등 출생. 카르멘의 영혼 치료 연구소 → 조율자 가리온 습격(공멸일: 구 H사 폐업).
- 972년경 이전: **연기 전쟁** (구 L사·구 G사 패전 폐업. 우제트 전멸).
- ~10년: 로보토미 코퍼레이션이 L사가 됨 (Lobotomy Corporation 본편).
- **백야·흑주**: 빛의 씨앗이 도시 전역에 뿌려짐 → 로보토미 몰락, L사 둥지 공석·안개, 손가락들의 L사 둥지 쟁탈전. **뒤틀림 시작**(9구 피아니스트, 30만 사망).
- 도서관 개장 (Library of Ruina 본편, 982년 여름 추정) → 두 번째 백야 → 도서관 외곽 축출.
- 983년: Leviathan (베르길리우스).
- **984년 1월 ~ 985년**: Limbus Company 본편 (LCB 수감자들, 황금가지 회수). 3월 K사 봉이 아빠, 5월 K사 기술해방연합, 7월 대호수, 10월 T사 뒷골목 검계, 11월 워더링하이츠, 12월 T사 시간 살인마·라만차랜드 토벌, 985년 1~2월 H사 가주 심사·거미집 와해.
- 985년 6월: 인구 67억→64억 급감 (D사 축출설).
- 미래: 2차 연기 전쟁(확정 아님), 13 협회(뒤틀림 전담) 발족 준비 중.

## 12. 세계관 톤 (작가 노트)
- 사이버펑크 디스토피아 + 실은 중세 판타지 RPG 구조: 둥지=성벽 도시, 뒷골목=빈민가, 해결사=모험가+용병, 조직=도둑길드, 외곽=몬스터 필드, 유적/매몰 로보토미 지부=던전.
- 반복 클리셰: **"의도는 좋았다"**. 손가락도 원래 유교 덕목 구현을 위해 생겼다가 망가졌다는 추측.
- 음악하는 놈 치고 제정신인 놈 없다(롤랑).
- 윤동주 시 인용(재해 등급 문구). 인물 대사에 냉소·블랙유머.
