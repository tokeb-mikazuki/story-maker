# 02. 날개(Wings) — 26개 초거대기업과 각 구역

> 출처: 나무위키 「날개(Project Moon 세계관)/목록」, 「K사」, 「Time Track」, 「Warp Corporation」, 「홍원생명공학그룹」, 「Nagel und Hammer」, 「살피뼈 농축산」, 「R사」, 「U사」, 「P사」, 「J사」, 「Lobotomy Corporation(Project Moon 세계관)」
> 시뮬레이터에서 **출생지·거주지·취업처**로 쓰일 핵심 자료. 각 날개 = 하나의 구(區) = 둥지 + 뒷골목.

## 0. 날개 일반 구조
- 날개 = 특이점(=알)을 쥔 대기업. 둥지 하나를 관할(지방정부 역할). 둥지 주민에게 세금 → 날개는 머리에 세금.
- **시민권 부여·몰수 권한.** 둥지 거주는 돈 + 날개 허가.
- 자체 무력(사병). **직원 등급은 숫자형, 숫자가 클수록 높음**(1등급 말단 ~ 5등급 고위. T사 5등급 감사직, W사 4등급 정리요원 등). 구 G사만 사원·대리·부장식.
- 직원 대우: 둥지 주민 중에서도 상급이지만 사축. 기밀 때문에 퇴사 시 기억 처리. 계약서에 '필요 시 희생' 조항.
- **날개 몰락 사유**: 사고 자폭 / 날개 전쟁 패배 / 머리 금기 위반으로 폐업 / 특이점 유출. → 둥지는 무법지대(알박기). 전 직원은 낙인, 유능하면 타 날개 스카웃.
- **특허**: 몰락 날개의 특이점 특허 만료 시 공용화(강화 문신, 공간 왜곡 등). 다른 날개·머리가 특허를 사서 독점하기도(W사의 차원 열기).
- **특허 전쟁**: 서류로 하는 분쟁. 아랫사람들(소송에 엮인 실무자·해결사)이 오히려 이득 보는 구조.
- 특이점의 기원: 창립자가 **외곽 너머의 '별'에게 소원**을 빌어 얻었다는 정황(K사, T사).
- 날개끼리 특이점 협력 관계: 구 L사/로보토미(에너지) – T사(시간) – W사(이동·시간 공급) – R사(무력) – K사(앰플).
- 건축 양식은 인접 날개와 닮음(R사만 예외, W사 닮음).
- 지역 배치: 1구 A사 중심 나선형. 문화권은 방위별(01 문서 참고).

## 1. 머리 (A·B·C사) — 날개이자 중앙정부
| 사 | 구 | 역할 | 구성원 칭호 |
|---|---|---|---|
| **A사** | 1구 | 조세·조폐·입법·행정·사법. 특허·날개 자격 심사. 도시의 금기 제정. 특이점 규칙 조율(T사·R사 특이점에 규칙 부여) | **조율자**(Arbiter 추정) |
| **B사** | 2구 | 정보 공기업. 이상현상·위법 감시, 축출 작업 | **응시자**(Beholder 추정) |
| **C사** | 3구 | 군사 공기업 + 세무 집행(징수·탈세자 처벌). 금기 위반자 처형 | **발톱 / 처형자**(Claw). 특이점 혈청(혈청K는 K사 특이점 응용 추정) |
- 수익 사업 안 함, 날개들의 세금으로 운영.
- 경미한 금기(세금 미납 3회 경고 후, 특허료 미지불)엔 발톱, 중대한 건엔 조율자.
- 대중의 인식: 일반인은 머리를 '이해 불가능한 절대권력'으로 두려워함. 구 H사 터엔 조율자가 홍차 마신 테이블이 경고로 보존됨.

## 2. 현존 날개 상세 (정보량 많은 순 강조)

### ★ K사 — 11구 / 제약·축산 / 서유럽(독일어 지명)
- 특이점(공식): **HP앰플** — 세포 자생 나노머신. 뇌만 멀쩡하면 목 부러짐·사지 절단도 순식간에 복구. 의체도 복구. 매우 비쌈(협회도 함부로 못 씀).
  - 진실: 창립자 스테파네트의 동료가 별에게 소원을 빌어 변한 **'눈물 흘리는 것'**(거대 눈알)이 잔혹한 영상을 보며 흘린 눈물을 정제한 것. 맞은 사람을 **본인이 인식하는 원형**으로 되돌림. 덜 정제 = **붕괴 앰플**(사람을 녹임). 고문에도 사용(망가뜨리고 치료 반복).
  - 축산 응용: 다리 6개·날개 8개 닭(**보살 치킨**). GMO 같은 거부감 → "K사 특이점 미사용 원료육" 문구.
- 둥지: 근미래풍, 치안 매우 좋음(해결사 싸움을 연예인 보듯 사진 찍음). 너무 평탄해서 주민들 의욕·꿈 없음. 에메랄드빛 조명. **최소 주 70시간 근무**. 검문소(비자 필요).
- 장소: 번화가, 보살 치킨, 은봉이네 호프집(순종 닭, 경쟁에 밀려 사장 뒤틀림), 햄햄팡팡, GoGi 고기 MEAT, **칼프 마을**(의체 산업 성지, N사 이단심문관에게 학살 — K사가 눈물 확보 위해 방조), 식량자원개발부 연구소.
- 11구 뒷골목: **떡갈나무 마을**(동화풍, 실은 매달 한 명에게 주민들의 뒤틀림을 주입해 지하에 가두는 의식).
- 금기: 검문소 난동·기물 파손(K185) → '코드 퍼플', 적출직 출동.
- 직원: **적출직**(면역계 비유; 트롬보사이트·루코사이트). 1~2등급 = 진압방패·진압봉 시위진압대 스타일, HP탄으로 즉시 회복. 3등급 = 분리형 쌍날검, 평소엔 시험관 속 **가사 상태**로 대기(꿈도 안 꿈, 인격 메마름). 특수적출직. **앰플 드론**: 치명상일 때만 투여 → 직원들이 일부러 팔을 잘라 치료받음. 도주자는 붕괴 앰플로 처단.
- 전속 해결사 지크프리트를 연예인·히어로처럼 밀어줌(사진 찍으려면 K사 허가).
- 대외: 연기 전쟁 로보토미 편. 전후 I사와 함께 "날개 전쟁 참전자는 우리 둥지 이주 불가" 규정으로 고용 해결사들 뒤통수. 기술해방연합의 테러 대상.

### ★ T사 (Time Track) — 20구 / 제조 / 산업혁명기 영국·스팀펑크
- 특이점: **시간 조작**. 실은 미리 확보한 **시간을 연료로** 시간을 조종(시간세 + W사 워프열차 승객의 시간).
- **시간의 화폐화**: 시계 = 신분증 겸 지갑(회중시계). 시간 은행에서 전날 인출. 중산층 하루 20~28시간, 부자 100시간+, 공장 노동자 ~10시간, **법정 최소 4시간**(8시간 자면 이틀이 지남). 부자는 말이 빨라 녹음기로 느리게 틀어 대화. 노동자가 시간 없어 일 못하면 "게으르다" 비난.
- **시간세**(돈 또는 시간으로 납부). 체납 시 단축된 하루로 노동 / **시간 저울 교수대**로 강제 추출. 외부인은 선불 납부. 시간 로또(최대 100억 안).
- **색 추출기**: 자격 없는 자는 색을 못 가짐 → 흑백·세피아 도시. 돈 내면 색을 돌려받음(코트·바지 정도는 서민도 무리하면 가능, 부자는 안경테·꽃까지). 색 = 부의 척도. 본래의 색을 밝히는 랜턴.
- 12개 시계탑(A사 시간축). 공장 매연으로 하늘 어두움. 둥지 아이들은 나이 되면 공장 강제노동.
- 발명 장려(연례 발명 경시대회, 자격증 필요) + **무허가 기술 개발 엄금**(압송 후 행방불명).
- 치안 나쁨: 시간 강탈 갱단, 유로지비 폭탄테러, 뒷골목 자경단(데드레빗츠)이 둥지까지 지킴.
- 기술: TT2(격리공간 시간 루프, 로보토미에 적용), TT4(시간 동기화, 매우 비쌈), TT5-2(시범), **수면 캡슐**(30분=6시간 숙면, 직원 복지), 골든타임(치명상 시 회복 가속), 특수 냄비(10초=3일 끓인 스튜), 1초에 천년을 겪게 하는 암살 장치, 시간 금고.
- 직원: 정장+실크햇(**고등급일수록 모자가 높음**). 징수직(2~4등급, 징수곡괭이, '시곗줄'이라는 멸칭, 횡령도), 강력징수직, 미래절단직, 감사직(5등급, 커스토디안 헬멧). 신문 「티타임즈」.
- 20구 뒷골목: 둥지처럼 칙칙, 시계가 신분증, 시간 강탈 항쟁, **폭탄 쓰는 조직 많음**. 유로지비 아지트(물물교환 시장).
- 대표 허버트(H.G. 웰스 모티브). S사에서 도망친 사람들이 많이 넘어옴(쉬운 왕래), S사 도주민 강제송환 암약 가능성.

### ★ W사 (Warp Corporation) — 23구 / 운송 / 푸른 색조
- 특이점(공식): 공간이동 → **워프 열차**(도시 내 가장 빠르고 안전한 장거리 이동, 비쌈, 1등석·일반석, 냉동수면). 패키지 여행 상품도.
  - 진실: **현상 복구**. 열차는 실제로 수천 년 동안 차원을 헤매고, 승객들은 그 사이 미치고 서로 엉겨 붙음. 도착 후 **정리 요원**이 살점을 정리하고 승차 시점 상태로 복구. 승객 시간은 T사에, 감정은 W사 특이점에 사용. 소문 수준 의혹("1등석 승객 실종").
- 984~985년 현재 **경영 위기**(로보토미 몰락, 실종 사건, 혈귀 사건) → 푯값 인하, 일반석 증가, 승객 질 저하. 신생 'Wayfarer Company'가 W사 자리를 노림.
- 23구 뒷골목: **도시 최악의 마굴 중 하나** + "맛의 골목". 살인 일상화, **인육 식당 넘침**(재수 없으면 식당에서 밥 먹다 재료가 됨). 보랏빛 소금 특산. 피에르의 고기파이. 칼리·레스티 출신 — "23구 출신"이라는 말 한마디로 납득되는 동네.
- 정리 요원: 야근 일상, 매뉴얼 강압, '자살자들의 곱창파티' 목격, 정신 못 버티면 기억소거 후 퇴사(라고 알려짐).

### ★ H사 (홍원생명공학그룹) — 8구 / 제약·보험 / 중국·무협+미래기술
- 8구 전체가 **구룡채성 같은 초거대 건축물 '홍원'**. 중앙 둥지, 테두리 뒷골목(천장으로 막혀 햇빛 없음). 건물이 주기적으로 이동 → 길잡이 필요. 일부 구역은 유적과 연결.
- 역사가 수백 년. 지배 가문만 바뀌며 '홍원'과 특이점 '환' 유지. 대표 = **가주**(가주 심사로 선출). **4대 가문**(가·사·설·왕) + 이사회. 지하의 **선인**들.
- 특이점: **환(丸)** — 신체 치료·강화·변형·부활까지 만능 약. 섭취·고약·붕대. 도교 연단술·음양오행·팔괘 기반, 제조 시각 따라 효과 달라 양산 어려움. 부작용(체계 다른 환끼리 충돌, 단골일수록 심함, 몸에 식물 등 비인간 특징 발현). 아편 모티브 추정. 인체실험(죄수, 연구원 자기 복제 후 7일 내 폐기).
  - **생명 보험**: 사망 시 부활 특약(뇌 손상 시 불가, 기억 풍화·신체 변질 → 금기 회피). 부활 시 성격·신체 조작 가능. 뒷골목 기준 갱신비 어마어마. 저가 보험은 하자.
  - **흑수환**: 십이지 아인종 능력을 쓰는 12흑수. **충**: 사람으로 만든 기억 벌레(세뇌 도구).
- **재적일(再積日)**: 매달 하루, 종소리와 노래와 함께 건물이 레일 타고 재배치 → 노동가치·소득에 맞춰 방 크기 재분배. 하루아침에 집에서 쫓겨남(떨어져 죽거나 압사). 주민들은 당연시. ("오늘은 몇 명이 떨어지고 몇 명이 버텨내려나")
- **공멸일**: 구 지배가문 공씨가 아인종(조길인) 창조 금기로 조율자에게 멸문(실은 가모의 함정). 이후 4대 가문은 머리를 트라우마급으로 두려워함.
- 성탄절에 평안 기원 사과 선물. 의료 관광 명소.
- 금기: 구역마다 다름. 절도 등 → 죄인 → 환 개발 생체실험 대상.
- 985년 1~2월 가주 심사(가시춘 즉위) → 권력 공백에 K사 특수적출직·R사 제2무리·엄지 등이 홍원 침공.

### ★ N사 (Nagel und Hammer, 못과 망치) — 14구 / 제조·관광 / 독일+프랑스
- 사상: **인간성 탐구, 경험 중시**. 고통도 겪어야 할 경험 → **의체 혐오**. 파벌 '못'/'망치'. 극단파 **이단심문관**(의체 사용자·시술자 학살, 망치 크기로 계급: 작은 망치 등). "보이는 것에 집착하는 회사".
- 특이점(추정): **기억·경험 추출 및 주입**. 상품 **경험 통조림**(시지프 백화점 브랜드 독점; 허여멀건 죽, 먹으면 경험이 녹아드는 느낌. 자극적으로 변조된 보급형 → 중독, 거짓 경험을 실제로 믿음). 특수 필름(순간의 경험 추출), 구식 도구 '못'.
