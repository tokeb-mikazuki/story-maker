# 03. 해결사 · 협회 · 사무소 · 공방

> 출처: 나무위키 「해결사(Project Moon 세계관)」 외. 플레이어 커리어 루트의 핵심 축.

## 1. 해결사(Fixer) 개요
- 돈 받고 의뢰를 처리하는 도시의 하청업자. 모험가+용병+흥신소. 고양이 찾기 ~ 도시의 별 토벌까지.
- 업무: 전투·청부살인, 정보 거래, 경호, 조사, 수집, 탐정, 법무, 운송 등.
- **면허제**: 하나 협회가 면허·등급 관리. 모든 해결사에게 **FIN**(Fixer Identification Number). 상벌점제 → 벌점 누적 시 강등·면허 박탈.
- 보통 **20세 이후** 데뷔(규정인지 관습인지 불명. 에즈라는 15~18세에 연기 전쟁 참전).
- 무면허로 해결사 같은 일을 하는 조직도 있음(협회와 엮이기 싫어서).
- 520년 전에도 존재한 오래된 직업.
- 저등급은 강화시술 거의 필수(맨몸+싸구려 공방무기로 시작한 핀은 금방 죽을 거란 평가 받고 실제로 죽음).

### 실상 (톤)
- "해결사는 사무소가 관리하고, 사무소는 12협회가, 12협회는 하나 협회가 관리해. 껍질에 껍질을 두른 종속된 삶." (7급 해결사)
- 저등급: 밑바닥 인생. 조직이 시덥잖은 이유로 사무소를 습격(**사무소 깨기**).
- 고등급도 한 번의 실수로 죽음. 특색 주홍십자도 전멸.
- 협회/후원 소속은 안정적이지만 **소속·후원자의 의뢰는 거부 불가**(전멸이 뻔해도).
- **계약 사기**가 흔함 → 공증(계약) 사무소가 중요.

## 2. 등급 (9급 → 1급, 특색)
- 실적 기반 = **신용도**에 가깝다. 강함과 정비례하지 않음 (사고·행실·활동 감소로 강등, 고위험 의뢰 회피 시 정체, 자격증으로 승급한 사례도).
- 처리한 의뢰는 내용·의뢰인·해결방법까지 **하나 협회에 보고** → 승급/강등 심사.
- 등급 높은 사람이 낮은 사람 밑에서 일하기도 함(5급 모제스 밑의 1급 베스파).
- 복장이 밝고 화려할수록 고등급일 가능성.

| 등급 | 수준 / 할 수 있는 것 |
|---|---|
| 9급 | 최하위. 밤 되기 전 고양이 찾기. 무기 든 일반인 수준, 쥐보다 조금 번듯 |
| 8급 | 최소한의 신체 강화. 2인 이상 사무소 개업 가능. 여전히 초짜 취급 |

| 6급 | 경력자. 협회 말단(6과) 직소속, 말단 직속 사무소 대표 가능. 소속이 갈리기 시작 |
| 5급 | 둥지 기준으로도 쓸 만함. 둥지 내 사무소 소속, 협회 6과 부장 가능. 개인 의뢰·유명세 시작 |

- 실제 인물 예시: 9급 롤랑(강등), 8급 윤·유리, 7급 마스, 6급 산, 5급 모제스·월터, 4급 유나, 3급 에즈라·살바도르, 2급 장뢰, 1급 에드가·로웰·네모·지크프리트.
- 도시 최강 후보(롤랑 언급): 쪽빛노인, 하겐, 운검(S사), 지크프리트(K사), 간류, 아토스, 가치우(소지/옥기린), 르노(리날도).

## 3. 사무소
- 1인 ~ 수천 명(구 우제트 2000명+). "해결사 수만큼 사무소가 있다." 금방 생기고 금방 사라짐.
- 고객 신뢰를 위해 지정복 권장(빡빡한 유니폼은 아님).
- 이름·종류는 실제 법조계 사무실에서 착안.
- **무소속 사무소**: 법적 지위 불분명, 신뢰도 낮음(배후에 조직 가능), 대신 싸고 규정 널널. **공개 의뢰**를 선착순으로 받음.
- **협회 직속(협력/지정) 사무소**: 안정적 봉급. 배정 의뢰는 사무소가 전멸해도 수행. 협회 소속 증명서.
- 대표 사무소 예시:
  - 윤 사무소(7급, 8~9급 모임, 궁핍, 의뢰 없음), 갈고리 사무소(살인마 고용, 사람 찢어 걸어둠), 불주먹 사무소(반지하, 가난), 투귀 사무소(14구, 2급인데 허름, 24시 연중무휴), 쐐기/새벽 사무소(형제 사무소), 지팡이 사무소(T사 후원 공증, 회사급 규모), 찰스 사무소(14명 소수정예), 멀티크랙 사무소(P사, 의체 전문, 4팔), 시선 사무소(광학장비 정보조사), 어금니 사무소(전기톱, 공방 전업), 삼도끼 사무소(8구, 1:1 결투), 송곳니 사냥 사무소(P사, 혈귀 사냥, 수백 년 운영), 베이야드(창, 쥐 모아 창립).
- 사무소 등급도 존재(세부 체계 불명).

## 5. 공방 (Workshop)
- 장비 제작·개조. 넓게 보면 사무소. 장인 = 해결사 면허 + **트레스 협회 공방 시험**(공방 조합 자격).
- 트레스 협회가 공방 장비를 심사 → 머리에 보고 → 세금. **미허가 물품 판매·유통 금지**(자가 사용은 OK). 심사 탈락 시 수정 조언해주기도.
- 공방 등급은 알파벳(S급 등).
- 생필품 공방, 해결사 굿즈(피규어·뱃지) 공방도 있음. 뒷골목엔 쓰레기로 만드는 이름 없는 공방.
- 북부 공방은 리본 등 장식.
- 예시: 묵 공방(동부 검, 발도 시 예리해짐), 알라스 공방(가속), 스티그마 공방(발화 도검, 단면에 문양), 로직 아틀리에(비싼 총·탄환), 유니온 공방(싸구려 생체장비, 원료는 시체, '어중이떠중이 공방'), 장미스패너 공방(공구형 무기), 유리아 공방(14구 프리미엄, 멤버십), 코오리 공방(빙결 장갑), 나미르 공방(G사 중력 건틀릿), 휠스 인더스트리(조립식 대검), 슈바르츠 인더스트리(의체), 파나르 공방(압박붕대), **재단사**(특수 원단), 사육제(검지 산하, 인간 실).

## 6. 해결사 협회 (12 + 1)
- 하나 협회 주축. 사건을 협회 특성별로 배분 → 협회가 해결사에게 분배. **머리가 공무를 안 하니 사실상 공무원·전문직 대체.**
- 협회 이름 = 각국 언어의 숫자 + 그 문화권 색채(세븐은 티파티, 리우는 중화요리). 설립 순서대로 번호.
- **동·서·남·북 지부 + 본부**. 지부장은 지부를 임의 운용 가능(부패 여지).
  - 동부: 동양풍 / 서부: 중세 기사 갑옷 / 남부: 정장·코트 / 북부: 테크웨어
- 각 지부 **1과~6과**: 1과 최정예(1급 부장, 1~2급 다수), 2과 1급 부장+2~4급, 3과~ 도시악몽급 투입, 4과 도시질병급, 5·6과 도시전설급. (하나 협회는 3과에도 1급 다수)
- 협회원은 거부권 없음("충실한 강아지들").
- 입회: 협회 시험(츠바이는 약식 의뢰 수행) 또는 스카우트.
- **개인 의뢰**(의뢰인→해결사 직접) / **공개 의뢰**(의뢰인→협회→해결사들에게 공개).
- 협회와 계약한 장소(호텔 등)에서 깽판 → 하나 협회 벌점 폭탄.
- 부패: 시 협회 남부지부장 셀마의 뒷거래, 츠바이 6과 부장 월터의 범죄조직과 뒷거래.

## 7. 시뮬레이터 활용 메모
- 플레이어 커리어로 "9급 면허 취득 → 무소속/윤 사무소 같은 영세 사무소 → 협회 6과 입회 → ..." 같은 승급 루트를 자연스럽게 짤 수 있음.
- 승급 = 실적(의뢰 완수 보고) + 위험 의뢰 수락 + 행실(벌점). → 스탯 '명성/신용' + '벌점' 두 축으로 표현 가능.
- 등급별로 받을 수 있는 의뢰·접근 가능한 지역·고용 가능한 경호·뒷골목의 밤 생존 확률을 연동.
- 계약 사무소 경유 여부 = 사기 이벤트 발생 확률.
