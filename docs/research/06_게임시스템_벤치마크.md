# 06. 게임 시스템 벤치마크 — 서울 2033 + 프로젝트 문 3부작

> 목적: 우리 시뮬레이터(LLM 없음, 선택지만으로 진행하는 인터랙티브 소설)에 가져올 만한 메커니즘을 뽑아둔다.

## A. 서울 2033 (반지하게임즈, 2018~) — 1순위 벤치마크

### A-1. 정체성
- 핵폭발 18년 후 폐허 서울. 도봉산 생존자 마을 출신 주인공.
- 장르: 제작진은 "텍스트 로그라이크"라 하지만 실은 **인터랙티브 픽션 + 랜덤 인카운터 + 자원 관리**.
- 화면: **상단 상태바 / 중단 서술 텍스트(타자기 출력) / 하단 선택지·인벤토리**. 일러스트 극소, 사운드 거의 없음. "책에 가깝다". 하단 페이지 번호.
- 화자 **'이야기꾼'**이 2인칭 존댓말로 상황을 읊음("어? 벌써 이 책 마지막 장이네요."). 이야기꾼이 게임 밖 개발자 페르소나로도 활동(기획자 노트, 배고픈 이야기꾼 이벤트, 만물상).
- 시각장애인 커뮤니티 호응 → **스크린리더 접근성**이 텍스트 게임의 강점.

### A-2. 자원 (각 최대 3칸)
| 자원 | 0이 되면 | 특성 |
|---|---|---|
| 체력 (사람 아이콘) | 사망 | 회복 기회 드묾. 대신 멘탈/돈을 버려서 회피하는 선택지 多 |
| 멘탈 (하트) | 스트레스로 사망 | 회복 기회 많고 잃을 기회도 많음. 메인스토리는 가족 살해로 -1칸 시작 |
| 돈 (동전/주머니) | 죽지 않음 | 툭하면 털림. 교환가치 있는 모든 것의 총칭. 3칸 상한 |
- **3칸이라는 극단적으로 작은 숫자** → 한 칸 한 칸이 무겁고, 직관적.
- 부활 수단: 의약품+응급처치(체력 0 시 소모), 의료용 나노머신, 유료 쿠키(판당 1회).

### A-3. 가젯 (Gadget) = 아이템 · 능력 · 상태
- 100종 이상. 판정·선택지 해금의 핵심.
- **선택지 표시**: 필요 가젯 보유 → 초록, 미보유 → 빨강(비활성). 미보유 선택지를 눌러 만물상으로 구매 유도.
- **숨은 분기**: 명시 요구가 없어도 보유 가젯에 따라 결과가 달라지거나, 아예 없던 선택지가 생김. (예: '거짓말 탐지' 있으면 우는 아이에게 "입에 침이나 바르고 오라" 선택지)
- 능력은 레벨이 있음(철학 Lv.3, 근력 10레벨 등).
- 상태 가젯: 감기·감염·통증·수배 중·저주 받음·불면증·벌레 공포증 등 (디버프도 가젯).
- 동료·애완동물도 가젯(리트리버, 길고양이, 예삐…).
- 문제점: 가젯 과다 → 각 가젯 효용 하락·뉴비 진입장벽. 해결책으로 **상위 분류 체크**('신체 능력' = 유도/근력/날렵함, '수리 기술' = 전기/기계공학) 도입.

### A-4. 진행 구조
- **메인 스토리(고정 분기)** + **랜덤 인카운터(대부분)** 조합.
- 인카운터 분류: 기본 / 주요 스토리 / 조건부(특정 가젯 보유 시 등장) / **위기 상황(한 모험당 1회)** / 하드 모드 전용 / 확장팩 / 레벨 보상 / 구매 이야기 / 시즌패스.
- 인카운터 형태는 대체로 단순: **주거나 / 뺏거나 / 요구하거나**. 선택에 따라 살이 붙거나 전개가 뒤집힘.
- 시작 시 배경 선택(후원자판): 5개 중 3개 랜덤 제시 → 시작 가젯 결정. ('준비된 전문가' 확장팩: 군인·소방관·요리사·조직폭력배 등 직업 30종으로 시작)
- 복수 메인 스토리(도봉산 / 코마 / 짐승소년 / 괴물 / 시뮬라크르), 레벨로 해금.
- 프리퀄 「유시진」: 체력/멘탈/돈 대신 **60분 시간 제한**(선택지가 최대 12분 소모), 랜덤 없는 선형 구조 = "능력치 관리를 턴수 관리로, 가젯 관리를 정보 관리로."

### A-5. 엔딩 — "정착 엔딩" (★핵심 아이디어)
- 플레이어가 원할 때 **'정착하기'**로 모험을 끝냄 → 그동안 쌓은 것들로 **에필로그가 조립**됨.
- 에필로그 = 여러 **조건부 단락**의 나열:
  - 단락 단위 조건: "까마귀 군주 처치", "판자 학교 재건", "이모의 친구 보유", "근력 10레벨" …
  - 단락 내부 문장 치환/추가: "(조건: 철학 Lv.3) 문장 추가", "(조건: 수배 중 상태 보유) 반성의 의미랄까요."
  - 다른 인물의 후일담이 내 행동(도와줬나/아닌가)에 따라 생사까지 갈림(밀라노).
- 엔딩 수집 시스템 + 점수 시스템.
- → **장점: 플레이어가 한 모든 일이 '기록'으로 돌아온다.** 짧은 판도 의미가 생김. 우리 '인생 시뮬레이터'의 "인생 결산"에 그대로 응용 가능.

### A-6. 메타 진행
- 경험치는 **죽거나 정착할 때마다** 누적 → 레벨업 보상으로 새 인카운터·메인 스토리 해금. (사망도 진척)
- 업적, 일러스트 갤러리, 일일 퀘스트, 레이드.
- 이야기꾼의 만물상: 판당 5회 원하는 가젯 구매(그 판 한정).

### A-7. 평가에서 배울 점
- 장점: 로컬(한국 사회문화) 디테일이 녹아든 분위기, 개성 있는 인물, 촘촘한 사이드 스토리, **설정 오류 적음**, 꾸준한 콘텐츠 추가.
- 단점: **운빨 과다**(3연속 강도, 방금 버린 아이템을 바로 요구), 부정적 인카운터 비율 과다(뺏기고 맞기만), 가젯 인플레, 숙련자/뉴비 격차.
- → 우리 설계 시 주의: 랜덤 이벤트 **가중치·쿨다운·연속 방지**, 긍/부정 비율 관리, 가젯 카테고리화.

## B. Lobotomy Corporation (2016/2018) — 관리 시뮬

### B-1. 직원 4가치관 (★스탯 체계 후보)
| 가치관 | 영문 | 게임 내 역할 | 패닉 시 행동 |
|---|---|---|---|
| **용기** | Fortitude | 최대 체력 | **살인** — 타인 원망, 주변 공격 |
| **신중** (지혜) | Prudence | 최대 정신력 | **자살** — 자책·체념 후 자해, 주변에 큰 정신 피해 |
| **자제** (절제) | Temperance | 작업 성공률·속도 | **배회** — 도망치고 싶어 뛰어다니며 주변 정신력 깎음 |
| **정의** | Justice | 이동·공격 속도 | **격리실 개방** — "억눌린 것들에게 자유를" |
- 각 스탯 I~V 등급, 통합 등급. 등급에 따라 대사(신입의 설렘 → 5등급의 해탈·냉소)가 변함. **가치관 × 등급별 독백**은 텍스트 게임에 그대로 쓸 만한 연출.
- 승급 시 성격(경솔한, 성실한, 냉혈적…)+별칭(신입, 고참, 베테랑, 학살자, 현자…) 랜덤 부여.

### B-2. 피해 4속성
- RED(신체) / WHITE(정신) / BLACK(신체+정신) / PALE(최대치 % 피해, 영혼).
- 방어구는 속성별 배율(내성 0.5 / 보통 1.0 / 약점 1.5 / 취약 2.0).

### B-3. 공포 피해 (★)
- 환상체 조우·동료 사망/패닉 목격 시, **(대상 등급 − 내 등급)**에 따라 정신력 %피해.
  - 여유(0%) / 침착(0%) / 긴장(10%) / 공포(30%) / 절망(60%) / 압도(100%, 즉시 패닉)
- "고등급 직원의 패닉은 저등급에게 고등급 환상체급 공포" → 강자의 붕괴가 주변을 연쇄 붕괴시킴.
- → 우리 게임: '목격' 이벤트(시체, 뒤틀림, 강자의 죽음)에서 **내 정신 등급 대비 충격 규모**로 멘탈 피해 산출 가능.

### B-4. 기타
- 작업 4종: 본능(굶주림 채우기)·통찰(환경 분석)·애착(교감)·억압(억누르기).
- 위험 등급: ZAYIN < TETH < HE < WAW < ALEPH.
- 한 번 죽은 직원은 끝. 사무직은 관리직 전멸 시 권총 자결. 슬로건 "FACE THE FEAR, BUILD THE FUTURE".
- 직원 독백 예: "믿겨지지 않아. 내가 날개에 입사하게 되다니." / "그래도 뒷골목에서 비루하게 살다 죽는 것보단 낫지." / "좀 더 일하면 가족들도 둥지로 이사올 수 있어."  ← **깃털의 인생관** 그 자체.

## C. Library of Ruina (2020/2021) — 덱빌딩 전투

- **빛** = 행동력(코스트). 매 막 1 회복, 적 처치/흐트러뜨림 시 회복.
- **주사위**: 각 책장(스킬)은 주사위 묶음. 참격/관통/타격 + 수비(방어/회피). 서로 굴려 **합**.
- **흐트러짐**: 체력과 별개의 '자세 게이지'. 0 되면 무력화.
- **감정 단계** (0~5): 사망·주사위 최대/최소값·합 승패로 **긍정(파랑)/부정(빨강) 코인** 누적 → 단계 상승 시 빛 최대치 증가 + 환상체 책장 선택(긍/부정 비율에 따라 각성형/붕괴형).
  - → 우리 게임: 하루/챕터 동안 누적된 긍/부정 감정 코인이 '각성' 또는 '붕괴' 계열 선택지를 연다.
- 보상은 승패가 아니라 **감정 고조 수치**로 결정 → "팽팽한 접전 끝의 승리"가 최상.
- **전투 표상**: 숨겨진 조건 달성 시 외형 장식+칭호+소소한 효과. 조건은 획득 전까지 비공개. → **업적=칭호** 시스템 차용.
- 재해 등급(도시 괴담→불순물)이 진행 단계 그 자체.
- 유일한 선택지 "용서한다/용서하지 않는다" — **단 하나의 무거운 선택**의 힘. 주제: 용서.

## D. Limbus Company (2023~) — 가챠 RPG

- **정신력(SP)** -45 ~ +45, 0에서 시작.
  - **코인 앞면 확률 = 50% + SP%** (5%~95%로 클램프). ★ 정신 상태가 모든 확률 판정에 직결.
  - 합 승리 +10, 강적 처치 +10, 아군 처치 동참 +5, 나보다 강한 아군 사망 시 −10~.
  - −30~−44: **사기 저하**, −45: **패닉**(행동 불가 / 자해 / 도주 / 광인(피아식별 불가) / 자살 / 배회 / 분함 / 슬픔 / 앙갚음 등 유형별).
  - 빼기 코인 인격: 정신력을 **낮게** 유지할수록 강함 → "미쳐야 강해지는" 빌드.
- **칠죄종 속성**: 분노(빨강)·색욕(주황)·나태(노랑)·탐식(초록)·우울(하늘)·오만(남색)·질투(보라). 스킬 사용 시 해당 **죄악 자원** 축적 → E.G.O 발동 비용. 같은 속성 연속 사용 = **공명**(위력 상승).
  - 뒤틀림 형태도 죄종과 매칭(물=우울, 전기=히스테리…).
- **E.G.O**: 강력하지만 정신력·죄악 자원 소모. 정신력 바닥이면 **침식**(통제불능, 피아식별 불가, 대신 흐트러짐 면역). **오버클록**: 1.5배 비용으로 침식 스킬을 의도적으로 사용(자원 부족 시 불안정).
- 합: 코인을 굴려 위력 비교, 진 쪽 코인 하나 파괴, 다 깨지면 패배. 속도 빠른 쪽이 먼저/합 빼앗기.
- 컨티뉴: 전멸 시 '광기' 소모로 상태 유지한 채 부활.
- 뒤틀림 일련번호: 위험등급-최대피해(1~10)-죄종-구번호-발생순서.
