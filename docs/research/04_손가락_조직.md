# 04. 손가락(Fingers)과 뒷골목 조직

> 출처: 나무위키 「손가락(Project Moon 세계관)」, 「엄지/검지/중지/약지/소지(Project Moon 세계관)」, 「도시(Project Moon 세계관)」 기타 조직 목록.

## 1. 손가락 개요
- 뒷골목 모든 조직의 정점, 5개 조직. 머리=도시, 날개=둥지, **손가락=뒷골목**. "뒷골목을 주물러 관리"해서 손가락.
- 모든 날개의 뒷골목에 지부. 상급 간부(언더보스·큰 형님·마에스트로 등)가 구역 담당.
- 규모·무력 날개급. 상급 간부는 특색급. 손가락끼리 전쟁 = 날개 전쟁급 피해.
- **손가락 걸기**: 손가락 간 회담. 다가오면 산하 조직까지 마찰 자제.
- 모두 극단적 규율, 외부인에게도 강요. 서로를 미치광이 취급.
- 직속 조직원은 **금색 휘장**.
- 사상 모티브: **유교 오상(인의예지신)이 결여·극단화된 형태** + 범죄조직 유형. "처음엔 덕목을 구현하려 했으나 도시에서 망가졌다"는 추측.
- 날개와 암묵적 교류(M사 월광석 판매, W사 열차 탑승, U사 미용실).
- 알박기 항쟁엔 손가락 전원 참가하는 편.
- 음모론: 다섯 손가락 위에 같은 손이 있다(뒷골목 헛소문 취급).

### 2.1 엄지 — 예(禮)
- 가장 현실적인 범죄조직 체계. 보호비는 **순수하게 돈**(둥지 사람에게도 부담스러운 고액). 대신 괴상한 일 안 시키고, 평생 저당도 아님. 상납금+예의만 지키면 이름 걸고 보호. 못 내면 즉시 손 뗌. 예의 어기면 보호비 냈어도 처벌.
- 계급: **대부 > (콘실리에레) > 언더보스 > 카포 > 솔다토**. 같은 계급 내 호봉 I, II, III, IIII.
- 규칙(신체 처벌): 허락 없이 말하거나 상급자 이름 부르면 **아래턱**, 거슬리게 하거나 거짓말하면 **혀**, 지시 실패면 **손목**, 하급자 관리 실패면 상급자의 **팔**. 대부의 뜻에 의문 = 즉결처형+아랫사람 숙청.
- 적도 계급 높으면 예우하고, **전력으로 싸우는 게 예의**.
- **외부인 비례계급**: 언더보스 이상 ≈ 날개 대표·도시의 별 / 언더보스 ≈ 날개 이사 / 카포 ≈ 1급 해결사·협회 직속·날개 고위임원 친인척 / 솔다토 ≈ 일반 해결사·일반 기업 부서원. → 조직원은 매일 밤 외부 집단 계급 공부.
- 권위 이관 규율, 솔다토는 군대식 집단생활. 탄환이 비싸 평소엔 개머리판·총검.
- 언더보스 1명당 산하 조직 20개+. 산하: 흑운회(동부풍, 강화 문신, 흑운도), 버림받은 개, 밤의 송곳, 7대 패밀리, 매듭파 등. 산하 공방이 탄환 공급.
- "겉으론 명예, 실상은 비겁한 수단 없이 임무 못하는 손가락"(베르길리우스).

### 2.2 검지 — 신(信)
- 모든 것은 **지령**대로. 검지의 보호를 받는 뒷골목 주민도 지령을 수행해야 함 → 완수하면 **무상 보호**. 돈 없는 주민들이 선호.
- 문제: 지령은 처음엔 간단(예: "옆집 생일 케이크에 바늘 3개를 넣어라")하다가 점점 기괴해짐. 판정 기준이 모호(자기 그림을 모든 방법으로 '죽였는데' 미수행 판정 → 전두엽을 으깨라는 지령). 이행해도 처벌받을 수 있고 불이행해도 무사할 수 있음. 느닷없이 "죽어라" 지령도.
- 지령은 **도시의 신**이 도시 사람들의 진동(후회·떨림)을 기록해 쓰는 것. 지하의 방직기·방직자가 '도시의 언어'를 번역. 파이프로 전령에게 전달. 쪽지(검지 인장)가 일반적. '검지의 지령'은 **도시의 별** 지정.
- 구성: 신탁 대행자 > 대행자(전투 간부, 처형 집행) / 전령(지령 전달) / 수행자. **수평적**, 배신 개념 없음, 감상 배제.
- 망토: 지령을 잘 수행하면 방직기 원단으로 길이를 늘림(지령 따를 때만 방어력). 검: 지령 수행 시 사슬이 풀림('해금').
- 지령 거짓 위조는 어렵지만 일단 유통되면 진짜처럼 취급. 지령 연구회 존재.
- 산하 재단사 **사육제**(인간 실 원단, 청소부를 먹음).
- 엄지와 L사 둥지 전쟁(엄지를 죽여라, 기간 무제한) → 엄지 잔당을 꼬챙이에 꿰어 전멸.

### 2.3 중지 — 의(義)
- 조직원 간 **가족 같은 의리**, 내부엔 관대. 외부인엔 가차 없음. 배신·무단이탈은 끝까지 추적.
- **앙갚음**: "중지는 잊지 않는다." 과잉대응이 기본(한 대 맞으면 훨씬 많이). 작은 형님 심기를 건드리면 사형. 소문: 작은 형님 옷에 아이스크림 쏟은 아이의 가족이 다음날 사라짐(사실확인 안 됐지만 다들 믿음). 헤어 쿠폰 도난 같은 사소한 일도 기록.
- **앙갚음 장부**: 127조+ 수백 항의 처벌 규정(예: "중지의 처벌을 피해다니면 다리부터 찢어놓는 극형", "아랫사람 관리 못해 중지 사람이 공격당하면 윗사람 참수", "쿠폰 도난범과 그 친분자 즉결처형"). 장부는 조직원 간 **실시간 공유**(클라우드) → 다른 구역 중지가 복수 대행. 서열 높을수록 큰 장부.
- 이길 가망 없으면 물러나 후일을 기약하는 융통성.
- 장점: **입단 쉬움**, 가입하면 중지 전체가 뒷배. 단점: 탈퇴 사실상 불가, 남의 원한도 같이 갚아야 함.
- 은혜를 입히면 보답(의리 사슬, 스티커 문신).
- 장비: **원한 문신**(원한 갚을 때마다 포상으로 하나씩 새김; 많을수록 강함; 피부를 벗겨도 제거 불가 = 낙인) + 의리 사슬. 맨몸 격투(무에타이).
- 계급: 큰 형님/큰 누님 > 작은 형님 > ... 제자. 산하: 쌍갈고리 해적단(U사).
- 모제스 평: "의리가 있든 말든… 그들은 과시하고 싶을 뿐".

### 2.4 약지 — 지(智)
- 예술 중시. 작품 제작·심사·해설·경매. **승진 = 윗 등급에게 작품 인정받기**. 재료 상당수가 인간·인간의 고통. 단, 잔혹성만으론 높은 평가 못 받음.
- 거점 = **갤러리**(미술관 역할, 스튜던트 교육). VIP 경매: 입찰자는 흰 천 쓰고 고개 숙임. 비엔날레.
- **보호 받으려면 작품 제출** → 입시미술 같은 홀에서 심사 → 학점. 낙제 1회 경고, 2회 보호 중단, **3회 즉시 처형**. 눈에 들면 스카웃. 주민들의 절박함 자체를 감상.
- "보이지 않는 예술은 의미가 없다."
- 계급: 마에스트로(상급 간부) > 도슨트 > 스튜던트.
- 파벌: **야수파**(동물 가면, 동물 신체로 작품, 물감 주입, 자체 동물원), 입체파(해체), 점묘파(붓 무기), 절대파, 신체파(인간 근육·뼈, 쇠퇴), 청기사파 등.
- 약지 예술 학원(아이들에게 가치관 주입). 외곽에서 소지와 항쟁 중.
- 실례: 마을 거주민의 머리카락을 봉한 항아리 5000만 안 낙찰, 살아있던 조직원 의식을 추출한 그림 「붉은시선」.

### 2.5 소지 — 인(仁)
- 인 = 하나의 의미 아닌 **각자의 신념**(선하지 않을 수도).
- **익명성**: 정체를 숨기고 다른 조직에 이중 소속. 몸의 **낙인**이 뜨거워지면 결집, 임무 후 흩어짐. 소집 없으면 서로 소지인지도 모르고 죽고 죽이기도.
- 정식 조직원 = **별**. 수호전 **36천강 72지살** 별의 이름(星名)과 별호. 별 이름은 평소 숨김. 공석이 생기면 적합자에게 계승.
- 제식 무기 = 유물('별이 벼려진' 검; 천살성도, 천퇴성도, 지혜성도, 천구성도…). 하나만 선택 가능, 욕심내면 몰락.
- 파편화 심함. 가치우(옥기린, 천강성; 해결사, 도시 최강 후보), 뇌횡(동부 엄지 카포 겸), 자로(흑수 겸).

## 3. 거미집 (손가락 공동 사업, 985년 2월 와해)
- 다섯 손가락이 공동 운영한 양성 기관. 각 손가락의 **아비**(스승)와 **제자**. 요시히데(료슈)를 '무엇이든 베는 검'으로 기르려 함. 실세는 검지 아비 뤼엔(배후 지령). 림버스 컴퍼니의 '거미집 태우기'로 와해.

## 5. 혈귀 (요약; 상세는 05 문서)
- 인간의 아종, 도시 거주 허용. 혈귀 전쟁 이후 음지에서 조용히 공존. 장로가 둥지 하나씩 관리. 권속·피주머니. 호텔 라리에르, 러스크 사무소(낮엔 모르는 혈귀 해결사), 라만차랜드.

## 6. 시뮬레이터 활용 메모
- **뒷골목 거주 시 '어느 손가락의 보호 구역인가'**가 생활 규칙을 결정 → 지역별 '보호 대가' 이벤트:
  - 엄지 구역: 매달 상납금(돈) + 예의 체크(말실수 이벤트 → 턱/혀).
  - 검지 구역: 랜덤 지령 쪽지(처음엔 사소 → 점점 기괴). 수행/불이행 판정은 불투명(확률).
  - 중지 구역: 사소한 마찰이 장부에 오르면 끝없는 추적. 가입은 쉽지만 탈퇴 불가.
  - 약지 구역: 정기 작품 심사(학점), 3회 낙제 처형. 예술 스탯/창의 판정.
  - 소지: 평범한 이웃이 사실 별일 수도. 낙인 이벤트.
- 조직원 루트: 산하 조직 말단 → 손가락 직속(금휘장) → 간부.
