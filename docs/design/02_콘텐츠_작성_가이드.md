# 02. 콘텐츠 작성 가이드 (YAML)

모든 이야기는 `src/content/` 아래 YAML 파일이다. 코드를 몰라도 이벤트를 추가할 수 있다.
작성 후 `npm test`를 돌리면 오타·없는 goto 대상·잘못된 능력 이름 등을 잡아 준다.

## 파일 구성
| 파일 | 내용 |
|---|---|
| `origins.yaml` | 출생 배경 (시작 시 3개 무작위 제시) |
| `events/*.yaml` | 이벤트. 폴더 안 아무 파일에나 넣어도 됨(단계별로 나눠 둠) |
| `actions.yaml` | 성인기 월간 행동 메뉴 |
| `endings.yaml` | 종료 사유별 결산 첫 문장 |
| `epilogue.yaml` | 결산 조립용 조건부 단락 |

## 이벤트 필드
```yaml
- id: adult.example          # 고유 ID (단계.이름)
  kind: encounter             # encounter(기본) | story | night | crisis
  stage: adult                # child | teen | adult (생략 시 아무 단계)
  age: [20, 40]               # 나이 범위 (선택)
  date: ['984.01', '984.12']  # 날짜 범위 (선택) — 원작 사건 '소문'에 사용
  fixed: true                 # 조건이 맞으면 그 턴에 반드시 먼저 발생 (역사 이벤트)
  once: true                  # 평생 한 번
  cooldown: 6                 # 다시 나오기까지 최소 턴 수
  weight: 10                  # 랜덤 가중치. 0이면 goto로만 도달
  group: night                # 같은 group은 연달아 나오지 않음
  tone: negative              # positive | negative | neutral (부정 이벤트 연속 완화에 사용)
  when: { tag: 거주=뒷골목 }   # 발생 조건
  title: 제목
  text: |
    본문. {이름} {나이} {날짜} {구} {거주} 사용 가능.
  choices:
    - text: 선택지
      requires: { money: { gte: 100000 } }   # 미충족 시 회색 + 이유 표시
      hidden: true                           # 미충족 시 아예 숨김
      check: { ability: 화술, difficulty: 2, bonus: 10 }   # 확률 판정
      success: { text: ..., effects: [...], goto: 다음이벤트ID }
      failure: { text: ..., effects: [...] }
    - text: 판정 없는 선택지
      outcome: { text: ..., effects: [...] }
```

## 판정
`성공률 = 50 + 15 × (능력 − 난이도) + 정신 × 0.5 + bonus`, 5~95% 사이.
`check`에는 `ability`(전투·기술·화술·학식·예술·은신·생존·사업) 또는 `virtue`(용기·신중·자제·정의)를 쓴다.

## 조건 (when / requires)
`all` `any` `not` 조합 가능.
- `tag: 키` 또는 `tag: 키=값` — 예: `tag: 직업=해결사`, `tag: 신체:강화문신`
- `tagNum: { key: 해결사등급, gte: 1, lte: 4 }`
- `ability: { 전투: 3 }` · `virtue: { 용기: 2 }` (이상)
- `money / hp / sp: { gte, lte }` · `age: [min, max]` · `date: [from, to]`
- `stage: adult` · `seen: 이벤트ID` · `sinTop: 분노`

## 효과 (effects)
`hp` `hpMax` `sp` `money` (증감) · `fear: 1~5` (공포 피해) · `addTag` / `removeTag` · `tagAdd: { key, value }` (숫자 태그 증감) · `virtue: { 용기: 1 }` (경험치) · `ability: { 전투: 1 }` (레벨) · `emotion: pos|neg` · `sin: 분노` · `advance: 개월` · `end: 종료사유`

## 태그 규칙
| 키 | 의미 |
|---|---|
| `거주` | 둥지 / 뒷골목 / 무등록 (생활비·밤 위험 결정) |
| `출신`, `출신구`, `가정`, `보호` | 출생 배경 |
| `직업` | 깃털 / 해결사 / 조직원 / 공방견습 / 공방장인 / 소시민 |
| `월급`, `생활비`, `상납금` | 월말 정산 (숫자) |
| `해결사등급`, `직원등급`, `조직서열`, `실적`, `숙련`, `근속`, `조직공헌`, `명성` | 커리어 수치 |
| `신념` | 백야에서 얻음. 목소리 이벤트에서 E.G.O 발현 조건 |
| `상태:*` | 상태이상 (중지장부, 금이간마음…) |
| `신체:*` `소지:*` `인맥` `적` | 몸·소지품·관계 |
| `이번달:*` | 그달 말에 자동 삭제 (`이번달:야간` = 뒷골목의 밤 노출) |
| `기록:*` | 화면에 안 보임. 결산(epilogue)용 플래그 |

## 톤 원칙
- 2인칭 존댓말, 건조하고 냉소적이지만 다정하게. 장면 끝에 한 줄짜리 뼈 있는 문장.
- 원작 고유명사는 그대로 쓴다. 원작 인물은 **소문·목격(카메오)**까지만 쓴다.
- 원작 설정과 충돌하지 않게 `docs/research/`를 먼저 확인한다(예: 햄햄팡팡은 로보토미 설립 이후에 생김, 뒤틀림은 백야 이후에만 있음).
