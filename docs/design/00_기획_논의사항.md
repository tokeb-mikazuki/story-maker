# 00. 기획 논의사항 (초안)

> 리서치를 바탕으로, 본격 설계 전에 정해야 할 것들. 각 항목에 **제안(기본안)**을 적어둠.

## ✅ 확정 (2026-10-12)
| 항목 | 결정 |
|---|---|
| 플랫폼 | **웹** (Vite + TypeScript, 프레임워크 없음, 콘텐츠는 YAML) |
| 인생 범위 | **출생부터 사망까지** |
| 시대 | **984년** — 기본 출생년 964년 → 984년에 20세(성인 진입). 유년기에 연기 전쟁(~972), 청소년기에 로보토미 시대와 백야·흑주(~982)를 겪는다. 985년 이후는 오리지널 전개 |
| 원작 캐릭터 | **카메오·소문 수준만** |

## A. 결정 필요 항목

### 1. 플랫폼 / 기술 스택
- 후보: ① 웹(HTML+JS, 브라우저에서 바로 실행, 모바일도 가능) ② Python 터미널 ③ 엔진(Ink, Twine 등)
- **제안: 웹(정적 HTML/TS) + 이벤트 데이터는 JSON/YAML 분리.** 서울 2033식 "상단 상태바 / 중단 서술(타자기) / 하단 선택지" UI 재현 쉬움, 배포 간단, 스크린리더 접근성 확보 가능.

### 2. "인생"의 범위
- 후보: ① 출생~사망 전 생애(연 단위 진행) ② 성인 이후 한 시기(수개월~수년, 일 단위) ③ 혼합(유년기는 빠르게 요약, 성인기부터 세밀)
- **제안: ③ 혼합.** 출생 배경 선택(구·계층) → 유년·학창기는 몇 개의 굵은 선택으로 압축 → 20세 전후 진로 분기(날개 입사 / 해결사 / 조직 / 공방 / 쥐…) → 이후 일·주 단위 진행. 사망 또는 '정착/은퇴' 시 인생 결산.

### 3. 시대
- **제안: 984년 전후 (림버스 컴퍼니 지옥편 시기).** L사 공석·뒤틀림 증가·W사 위기·13협회 준비 등 '불안정한 시대'의 소문/사건을 배경으로 깔기 좋음. 원작 사건은 뉴스·소문으로만 스치게(주인공은 무명의 도시인).

### 4. 원작 캐릭터 등장 수위
- **제안: 최소화.** 이름 있는 인물은 카메오(멀리서 목격, 소문, 단 한 번의 조우) 수준. 우리 오리지널 NPC 중심. → 설정 충돌 위험↓, 팬 서비스는 유지.

### 5. 텍스트 분량/톤
- 서울 2033처럼 '이야기꾼' 화자를 둘지? 도시라면 화자 후보: 단테의 노트풍 관찰자 / 무명의 기록자 / 2인칭 서술.
- **제안: 2인칭 서술 + 냉소적이지만 다정한 화자**("당신은 오늘도 살아남았습니다. 축하드려요. 내일도 그러시길.").

## B. 시스템 초안 (리서치 → 번역)

### B-1. 기본 자원
| 자원 | 표현 | 0이면 |
|---|---|---|
| 체력 | 수치 or 칸 | 사망(단, K사 앰플·H사 보험 등 '돈으로 산 부활/회복'이 존재) |
| 정신 | −45~+45 (림버스식) | −45: 패닉/뒤틀림 위기 이벤트 |
| 돈 | 안(眼) 실수치 | 거주 등록 만료 → 뒷골목의 밤 위험, 둥지 퇴거 |
| 시간 | 하루 시간대(새벽 3:13~4:34 = 뒷골목의 밤) | — |
- **확률 판정 = 50% + 정신 보정 + 관련 능력 보정** (림버스 코인 확률 차용, 5~95% 클램프)

### B-2. 성향 4가치관 (LobCorp)
용기 / 신중 / 자제 / 정의 — 각 I~V. 대사 톤·패닉 유형·특정 선택지 해금에 사용.

### B-3. 태그(가젯) 시스템 (서울 2033)
- 능력(레벨), 소지품, 상태(부상·중독·수배·장부에 오름…), 인맥(동료·적), 소속(협회·조직·날개), 신체(의체·강화문신·원한문신)
- 선택지: 조건 충족 시 표시/강조, 미충족 시 회색(이유 표시). 숨은 분기 허용.
- 상위 카테고리 판정(전투 기량, 기술, 화술 등)으로 태그 인플레 방지.

### B-4. 감정 코인 → E.G.O / 뒤틀림 (LoR + 원작 설정)
- 선택마다 긍정/부정 감정(+죄종 태그: 분노·색욕·나태·탐식·우울·오만·질투) 누적.
- 신념이 무너지는 사건에서 '목소리' 이벤트 → 플레이어가 "자신을 긍정하는가 / 놓아버리는가"를 선택 → **개화 E.G.O** 또는 **뒤틀림**(=게임오버 혹은 특수 엔딩).

### B-5. 공포 피해 (LobCorp)
- 목격 이벤트(시체, 청소부, 뒤틀림, 강자의 죽음)에서 (사건 위험도 − 내 정신 등급)으로 정신 피해 단계 결정.

### B-6. 지역 규칙 모듈
- 출신/거주 구역마다 고유 규칙 이벤트: K사 주 70시간, T사 시간세·색, H사 재적일, S사 노비·과거, N사 녹화 금기·입시, U사 대호수, J사 소망력·도박, 23구 식인 식당, L사 둥지 알박기.
- 뒷골목 거주 시 '보호 손가락'에 따른 규칙: 엄지(상납금·예의), 검지(지령 쪽지), 중지(장부), 약지(작품 심사).

### B-7. 커리어 트랙
- 깃털(날개 직원 1~5등급), 해결사(9급→1급, 사무소→협회 과), 조직원(산하→손가락 직속), 공방 장인, 버틀러, 고래잡이, 쥐, 입시촌 수험생…
- 각 트랙에 승급 조건·고유 위험·고유 이벤트 풀.

### B-8. 랜덤 인카운터
- 가중치 + 쿨다운 + 연속 방지 + 긍/부정 비율 관리(서울 2033의 단점 보완).
- 회차당 1회 '도시 재해' 급 위기 이벤트.

### B-9. 인생 결산 (서울 2033 정착 엔딩)
- 사망/은퇴/정착/뒤틀림/E.G.O 각성 등 종료 시, 조건부 단락을 조립한 에필로그. 만난 NPC들의 후일담이 내 행동에 따라 갈림.
- 재해 등급처럼 "당신의 인생은 [뜬소문 / 도시 괴담 / … / 도시의 별]로 기록되었습니다" 식의 최종 평가.

### B-10. 메타 진행
- 죽어도 해금(새 출생 배경, 새 이벤트, 칭호 — LoR 전투 표상식 숨은 조건 업적).
