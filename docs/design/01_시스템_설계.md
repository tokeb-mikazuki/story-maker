# 01. 시스템 설계 (v0.1)

> 확정 사항: 웹 / 출생~사망 / 984년(기본 출생 964년) / 원작 캐릭터는 카메오·소문.
> 이 문서는 엔진 구현의 기준이다. 수치는 플레이테스트로 조정한다.

---

## 1. 시간 모델 — 생애 단계

| 단계 | 나이 | 1턴의 길이 | 턴 수(대략) | 성격 |
|---|---|---|---|---|
| 유년기 | 0~12 | 사건 단위(마일스톤) | 4~6 | 출생 배경, 가정, 첫 '밤', 연기 전쟁의 소문(8세) |
| 청소년기 | 13~19 | 1년 | 7 | 학교/입시촌/조직 견습, 로보토미 시대, **백야·흑주(18세)** |
| 성인기 | 20~ | **1개월** | 가변 | 984년 1월 시작. 진로 트랙에 따른 월간 루프 |
| (자동 요약) | — | 1년 | — | 성인기 중 "평온하게 1년 보내기" 선택 시 연간 요약 판정 |

- 표준 시간은 A사 시간축(원작 설정). 게임 내 날짜는 `yyy.mm`.
- 성인기 한 달 = ①행동 선택 1회 → ②랜덤 인카운터 0~2회 → ③월말 정산(생활비·세금·상납금·노화) → ④조건부 '밤' 판정.
- 노화: 나이 들수록 체력 최대치 감소(돈으로 막을 수 있음 — 원작대로 부자는 늙지 않는다). 50세부터 '노인' 취급.

## 2. 플레이어 상태

### 2.1 핵심 자원
| 자원 | 범위 | 비고 |
|---|---|---|
| 체력 HP | 0~최대(기본 10, 용기·시술로 증가) | 0 → 사망 판정(회복 수단 있으면 소모 후 생존) |
| 정신 SP | **−45 ~ +45**, 시작 0 | 확률 판정에 직접 반영. −30 이하 '사기 저하', −45 '붕괴' 이벤트 |
| 돈 | 안(眼), 정수 | 음수 = 빚. 빚은 이벤트를 부름 |
| 거주 | 둥지(구) / 뒷골목 거주구역 / 무등록 | 무등록이면 '밤' 위험 |

### 2.2 4가치관 (Lobotomy Corporation)
`용기 / 신중 / 자제 / 정의` 각 **1~5** (경험치 누적으로 상승).
- 용기 → 최대 체력 +2/등급, 위협 맞서기 판정
- 신중 → 공포 피해 경감(정신 등급), 정보·계약 판정
- 자제 → 노동·반복 업무 효율, 유혹 저항
- 정의 → 행동 속도·도주, 신념 관련 선택지
- **정신 등급** = (신중 + 용기) / 2 반올림 — 공포 피해 계산에 사용.
- 붕괴 시 가장 높은 가치관이 붕괴 유형을 결정(용기=타인 공격, 신중=자기 파괴, 자제=도주·배회, 정의=해방 충동).

### 2.3 능력 (0~5)
`전투` `기술`(공방·수리·의체) `화술` `학식` `예술` `은신` `생존`(뒷골목 감각) `사업`(돈 감각)
- 상위 판정만 존재(서울 2033 가젯 인플레 교훈). 세부 맛은 태그로.

### 2.4 태그 (서울 2033의 '가젯')
문자열 키 + 선택적 값. 네임스페이스로 구분.
- `직업:해결사`, `해결사등급:9`, `소속:츠바이협회`, `보호:엄지`
- `신체:전신의체`, `신체:강화문신`, `신체:원한문신`
- `소지:차원가방`, `소지:K사앰플`
- `상태:부상`, `상태:중지장부`(중지의 앙갚음 장부에 오름), `상태:수배`, `상태:빚`
- `인맥:XXX`, `적:XXX`
- `신념:XXX` — E.G.O 발현 조건(아래 5장)
- `기록:XXX` — 결산(에필로그)용 플래그, 화면엔 안 보임

### 2.5 감정 코인 (Library of Ruina) + 죄종 (Limbus)
- `감정.긍정`, `감정.부정` 누적 카운터.
- 죄종 7종 카운터: `분노 색욕 나태 탐식 우울 오만 질투`. 선택지가 죄종 태그를 남긴다.
- 쓰임: 붕괴 이벤트의 분기, 뒤틀림 시 형태 결정(가장 높은 죄종), 결산 문구.

## 3. 판정

### 3.1 확률 판정
```
p = 50 + 15 × (능력 − 난이도) + SP × 0.5 + 보정(태그/가치관)
p = clamp(p, 5, 95)
```
- 난이도 0~5. 능력=난이도면 50% + 정신 보정.
- 정신이 +45면 +22.5%, −45면 −22.5% → **멘탈이 무너지면 모든 게 안 풀린다.**
- 선택지에 성공률을 '감'으로 표시(림버스식): 매우 불리 / 불리 / 반반 / 유리 / 매우 유리.

### 3.2 조건 선택지 (서울 2033)
- `requires`를 만족 못 하면 회색 + 이유 표시("필요: 전투 3", "필요: 소지:K사앰플"). 숨김 옵션 `hidden: true`면 아예 안 보임.

### 3.3 공포 피해 (Lobotomy Corporation)
목격 이벤트에 `위험도`(1~5)를 달고, `차 = 위험도 − 정신 등급`:
| 차 | 단계 | SP 피해 |
|---|---|---|
| ≤ −1 | 여유 | 0 |
| 0 | 침착 | 0 |
| 1 | 긴장 | −5 |
| 2 | 공포 | −12 |
| 3 | 절망 | −25 |
| ≥ 4 | 압도 | → 즉시 SP −45(붕괴) |

## 4. 뒷골목의 밤
- 성인기 매달 1회 '밤 판정'. 조건: 뒷골목 거주이며 (무등록 / 의뢰·행동이 야간 / 특정 이벤트).
- 오전 3:13 ~ 4:34. 녹취 금지·거주구역 불가침 외엔 모든 것이 허용.
- 청소부 3파(20분 청소 + 10분 휴식). 각 파마다 생존 판정(전투/은신/생존), 거주구역 진입 시도(문 두드리기: 화술), 실패 시 HP 피해.
- 거주구역 침입·파괴 선택지는 존재하되 선택 = **도시의 금기** → 발톱 → 사망 엔딩.
- 유년기의 '첫 밤'은 고정 이벤트(창밖으로 본 밤).

## 5. 붕괴 · 목소리 · E.G.O / 뒤틀림
- SP가 −45에 도달하면 다음 턴 시작 시 **'목소리' 이벤트** 강제.
  - "아름답고 따스한 목소리"가 당신을 위로하며 "원하는 대로 살라"고 속삭인다.
  - 선택: **받아들인다** → 뒤틀림(가장 높은 죄종 + 사유로 형태 결정) → 뒤틀림 엔딩(결산).
  - **거부한다** → `신념:*` 태그가 있으면 결의 판정(정의 + 신중 기반). 성공 시 **개화 E.G.O**(`신체:EGO` 태그, SP 0으로 리셋, 이후 강력한 선택지 해금). 신념이 없거나 실패 시 SP −30으로 회복하되 `상태:금이간마음`(다음 붕괴 시 거부 불가).
- 원작 설정: 백야·흑주(982년, 18세) 이전에는 뒤틀림이 존재하지 않음 → 그 전의 붕괴는 '자살/폐인' 같은 일반 결말.

## 6. 경제
- 월 생활비(거주 등급별): 무등록 0 / 뒷골목 거주구역 등록 ≈ 40만 안 / 뒷골목 중급 ≈ 120만 / 둥지 ≈ 300만+(날개별 차등, 세금 포함).
- 기준점(원작): 둥지 중상위층 월 400만 안, 특이점 뒷조사 의뢰 2억, 고급 전신의체 = 둥지 집 한 채.
- 등록 기한 만료 거주구역은 청소부 대상(원작) → 생활비 미납 2개월이면 '무등록'으로 전락.
- 보호비: 엄지(고정 상납금), 검지(지령), 중지(가입 시 무료·탈퇴 불가), 약지(작품 심사).

## 7. 진로 트랙 (성인기)
20세(984년 1월) 진로 이벤트에서 결정. 트랙마다 **승급 조건·월급·고유 이벤트 풀·고유 사망 위험**.
| 트랙 | 진입 조건 | 승급 |
|---|---|---|
| 깃털(날개 입사) | 둥지 대학/공채 합격(학식 판정) | 직원 1→5등급 |
| 해결사 | 면허(하나 협회) | 9급→1급(실적 + 고위험 의뢰 + 벌점 관리) |
| 조직원 | 손가락 산하 조직 | 말단 → 직속(금휘장) → 간부 |
| 공방 견습 | 트레스 협회 시험(기술) | 견습 → 장인 |
| 뒷골목 소시민 | 없음 | 가게·노동(안정적이지만 가난) |
| 쥐 | 실패의 끝 | 탈출 이벤트로만 벗어남 |
- 트랙 이동은 이벤트로 가능(해고, 사무소 깨기, 날개 몰락, 스카웃…).

## 8. 인카운터 스케줄러
- 이벤트 풀 필터: 단계, 나이 범위, 날짜 범위(역사 이벤트), 조건.
- 가중치 랜덤 + **쿨다운**(턴 단위) + **1회성 플래그** + **연속 방지**(직전 2개와 같은 `group` 제외).
- 긍·부정 균형: 최근 5개 중 부정 이벤트가 4개 이상이면 부정 가중치 ×0.5.
- 역사 이벤트(고정 시점): `date: 972.xx` 처럼 날짜에 반드시 발생(연기 전쟁 소문, 백야·흑주, 984년 이후 소문들).
- 생애 1회 **'도시 재해'** 급 위기 이벤트.

## 9. 사망 · 결산 (서울 2033 정착 엔딩)
- 종료 사유: 사망 / 뒤틀림 / 금기 위반(발톱) / 은퇴·정착(55세 이상 + 조건) / 노환.
- **결산 = 조건부 단락 조립**: 각 단락은 `when` 조건과 `text`, 단락 내부 문장도 조건부 추가·치환.
- 마지막 줄: 인생의 재해 등급 평가 — "당신의 인생은 **뜬소문**으로 남았습니다." ~ "**도시의 별**이 졌습니다." (명성·영향력 점수 기반)
- 사후 문구 예: 장례가 없으면 "뒷골목의 관례대로, 청소부들이 당신을 데려갔습니다."

## 10. 메타 진행
- localStorage: 해금된 출생 배경, 본 엔딩, 칭호(LoR 전투 표상식 숨은 조건 업적).
- 사망해도 해금이 쌓인다.

## 11. 화자 · UI
- 2인칭, 냉소적이지만 다정한 화자.
- 레이아웃: 상단 상태바(날짜·나이·HP·SP·안·거주) / 중단 서술(타자기 출력, 클릭 시 즉시 완료) / 하단 선택지 + 태그 보기.
- 접근성: 모든 정보 텍스트로, `aria-live` 영역, 키보드 1~9 선택.

## 12. 콘텐츠 포맷 (YAML) — 요약
```yaml
- id: child.first_night           # 고유 ID
  stage: child                    # child | teen | adult | any
  age: [6, 10]                    # 선택: 나이 범위
  date: [964.01, 999.12]          # 선택: 날짜 범위
  fixed: false                    # true면 조건 맞는 즉시 강제 발생(역사 이벤트)
  once: true
  weight: 10
  cooldown: 0
  group: night                    # 연속 방지 그룹
  tone: negative                  # positive | negative | neutral
  when: { all: [ {tag: "거주:뒷골목"} ] }
  text: |
    본문. {이름}, {구} 같은 변수 사용.
  choices:
    - text: 선택지 문구
      requires: { ability: { 은신: 2 } }
      check: { ability: 은신, difficulty: 2 }
      success:
        text: 결과 문단
        effects: [ {sp: 5}, {addTag: "기록:첫밤_목격"} ]
      failure:
        text: ...
        effects: [ {hp: -2}, {fear: 3} ]
```
상세 스키마는 `src/engine/types.ts`가 기준.
