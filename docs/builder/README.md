# 인터랙티브 소설 빌더 — 문서

웹에서 동작하는 인터랙티브 소설(텍스트 어드벤처) 제작 도구. RPG Maker 수준으로 세부 규칙을 커스텀할 수 있게 만든다.

| 문서 | 내용 |
|---|---|
| [01_패키지_스키마.md](01_패키지_스키마.md) | 패키지 형식, 엔진 동작, 수식·템플릿·명령·트리거 |

## 저장소 구성

| 경로 | 내용 |
|---|---|
| `packages/engine/` | 범용 엔진(의존성 0). 스키마, 수식, 진행, 검증기, 시뮬레이터 |
| `apps/studio/` | 웹 앱 '이야기 공방'(React): 홈·에디터·플레이어·테스트 플레이, 오리지널 샘플 2편 + 팬 창작 샘플 1편(`src/samples/`), 브라우저 테스트(`e2e/`) |
| ⚠ `src/samples/city984.ts` | **팬 창작('도시' 세계관, 원작 IP 있음).** 사용자 요청으로 비공개 테스트 빌드의 홈에만 노출. 공개 배포는 `VITE_PUBLIC_RELEASE=1`로 빌드해 제외할 것 |
| `fixtures/city/` | ⚠ **내부 테스트 전용·배포 금지.** '도시' 프로토타입을 툴 패키지로 재현한 것. 엔진 표현력 수용 테스트에만 쓴다 |
| `src/` | 옛 '도시' 프로토타입(수용 테스트의 비교 기준). 서비스에는 포함하지 않는다 |

## 실행

```
npm run studio            # 개발 서버 (http://localhost:5173)
npm run studio:build      # dist-studio/ (정적 사이트) + dist-studio-single/index.html (파일 하나)
npm run studio:preview    # 빌드 결과 미리보기 (http://localhost:4173)
npm test                  # 엔진·샘플·수용 테스트 전체
node apps/studio/e2e/smoke.mjs http://localhost:4173/   # 실제 브라우저(Edge) 클릭 테스트
node apps/studio/e2e/blocks.mjs http://localhost:4173/  # 블록 편집기·집필 모드·간단히/자세히·도움말·진행 로그 테스트
node apps/studio/e2e/audit.mjs http://localhost:4173/   # 모든 화면을 1280/1024 폭으로 찍고 넘침 찾기
```
