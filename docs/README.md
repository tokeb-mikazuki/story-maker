> 아래 '도시' 문서와 `src/`는 외부 IP 기반이라 서비스에 쓰지 않는다. 엔진 표현력 검증(내부 테스트) 기준으로만 남겨 둔다.

LLM 없이 플레이어의 선택만으로 진행되는 텍스트 기반 인생 시뮬레이터(인터랙티브 소설).
세계관: Project Moon의 '도시'(Lobotomy Corporation · Library of Ruina · Limbus Company). 벤치마크: 서울 2033.

## design/ — 기획
- `00_기획_논의사항.md` — 확정 사항(웹 / 출생~사망 / 984년 / 카메오) + 초기 제안
- `01_시스템_설계.md` — 시간 모델, 스탯, 판정 공식, 뒷골목의 밤, 목소리·E.G.O, 경제, 진로, 결산
- `02_콘텐츠_작성_가이드.md` — YAML 이벤트 작성법

## 실행
```
npm install
npm run dev     # http://localhost:5173
npm test        # 콘텐츠 검증 + 무작위/신중 봇 수백 회 인생 시뮬레이션
npm run build   # dist/ 정적 사이트
```

## 코드 구조
- `src/engine/` — 상태·판정·스케줄러·게임 진행·결산 (UI 없음, 테스트 가능)
- `src/ui/render.ts` — 상단 상태바 / 타자기 서술 / 선택지(1~9 키) / 특징 목록
- `src/content/` — 모든 이야기(YAML)
